# VNFest Forum v1 实施基线

## 本轮前端展示更新

- 移动端广场主题行以内容为主，保留头像、标题、摘要、作者/代表同好会短徽标和回复/点赞数字；活动时间与最后回复者在小屏隐藏，长身份在固定区域内省略。
- 帖子详情统一改为作者信息在上、正文在下的单列布局，桌面不再使用左侧作者 rail，作者身份可换行且不会遮挡正文。
- 主帖和回复的操作统一使用内联 SVG 图标按钮。按钮保持至少 44px 触控尺寸，提供 `aria-label`、`title`、`aria-hidden` 和点赞/收藏 `aria-pressed` 状态，数字统计仍保留。
- 以上仅是前端展示层调整，不改变 `display_club`、Forum API、权限、Markdown、附件或数据库契约。

## 1. 产品范围

Forum 是 VNFest 主站中的独立长期模块，自有页面、样式、脚本、API、迁移、测试、文档和上传目录全部位于 `Forum/`。主项目继续提供账户、通知、审计、限流、数据库、主题和公共背景能力。

当前产品只开放统一的论坛广场：

- `Forum/forum-plaza.html`：广场、最新回复、我的发帖、我的收藏、搜索、分类、排序和分页。
- `Forum/forum-post.html?id={id}`：主帖、连续回复楼层、点赞、收藏、分享、举报、编辑和管理。
- `Forum/forum-create.html`：发布广场帖子。
- `Forum/forum-create.html?edit={id}`：编辑自己的广场帖子。

广场允许访客浏览和搜索；登录用户可以发帖、回复和互动。广场内容管理只授予 `super_admin`。Forum 不再根据主站会籍赋予读取或管理能力，也不请求中日同好会目录。

## 2. 休眠范围与数据兼容

同好会相关功能采用“产品下线、数据保留”：

- 删除侧栏空间列表、移动入口、发布范围、空间分类、空间通知和空间管理动作。
- `bootstrap` 不返回 `memberships` 或 `post_scopes`。
- `list_posts`、`list_categories`、`list_mine`、搜索和管理队列只查询 `scope='plaza'`。
- `get_post`、回复、点赞、收藏、举报、编辑、删除和管理遇到历史空间内容统一返回 404。
- `create_post` 只接受省略 `scope` 或显式 `scope=plaza`；`scope=club` 或非空 `club_id/country` 返回 422。服务端始终写入 `plaza + NULL + NULL`。
- `manage_category` 已从公共动作移除；`manager` 和 `representative` 不再获得 Forum 权限。
- 不再创建 `forum_club_post` 通知。

旧的 `scope=club&club=...&country=...` 广场 URL 会使用 `history.replaceState` 清理三个参数、返回广场并显示一次中性提示，不请求休眠接口，不整页刷新。

以下数据和兼容字段继续保留，不迁移、不物理删除：

- `forum_posts.scope/club_id/country`。
- 空间分类、历史帖子与回复。
- 附件、标签关系、收藏、反应、举报、修订和既有通知。

重复执行 MySQL/SQLite 迁移只能创建或协调五个广场默认分类，不能清理休眠数据。未来恢复分区功能时，必须重新验证权限、国家隔离、搜索摘要、首图、附件、通知和管理链路。

## 3. 内容、安全与数据规则

- 标题最多 100 字，正文最多 50,000 字。
- 广场分类固定为：综合讨论、资源分享、活动发布、作品交流、求助答疑。
- 每帖最多 5 个标签，每个最多 20 个 Unicode 字符，合并空白并大小写不敏感去重。
- 正文保存为 Markdown。原始 HTML 转义；链接只允许 HTTP(S)；图片只允许当前用户上传并绑定的 `Forum/uploads/...` 附件。
- Markdown 支持 H2/H3、粗体、斜体、无序/有序列表、引用、行内/围栏代码、HTTP(S) 链接、Forum 图片和 `@提及`。标题字段本身是文章 H1。
- 图片按实际内容识别 JPEG/PNG/GIF/WebP，单张不超过 10MB，每篇内容最多 20 张。
- 编辑时按正文中的实际图片引用同步附件：仍被引用的保持绑定；新引用的临时附件绑定到内容；移除引用的旧附件转为 `post_archive/reply_archive` 并保留目标 ID，不能被临时上传删除动作物理清除。
- 头像使用账户已有 `avatar_url`。只允许 HTTP(S)、站内 `/data/avatars/...` 和 `data/avatars/{数字 ID}.{图片扩展名}?t={数字}`；失败时保持尺寸并回退昵称首字母。
- 所有 SQL 使用预处理参数；内容写入、计数、附件关系、标签和通知在事务中完成。写动作校验方法、登录、完整同源、权限、长度、状态和限流。

## 4. 广场与详情

论坛作者对象动态包含可空的 `display_club`，来源是账号主动选择的一个正式活跃会籍。广场作者、主帖作者栏和回复作者栏显示“同好会名称 · 会籍角色”；最后回复者仍只显示昵称。论坛不接收发帖时的代表身份字段、不保存身份快照，也不公开 `display_membership_id` 或全部会籍。中日同编号按 `country + club_id` 解析；失效会籍在写入生命周期中清除，读取时仍通过所有权、状态和正式角色联接进行第二道过滤。

广场使用连续高密度主题流。每条帖子显示 44–48px 真实头像、标题、置顶/精华、分类、两行安全摘要、作者、最后活动/最后回复者、回复/点赞统计和可选首图。手机头像为 36px，标题与摘要两行截断，首图约 88×64px。

`list_posts` 和帖子型 `list_mine` 项目提供：

```json
{
  "excerpt": "去除 Markdown 控制符后的正文摘要",
  "preview_image": {
    "url": "./uploads/2026/08/example.webp",
    "width": 1280,
    "height": 720,
    "alt": "example.webp"
  }
}
```

摘要最多约 180 个 Unicode 字符，移除图片语法、URL、原始 HTML 标记、脚本内容和控制字符；纯图片内容显示“图片帖”。首图只从当前授权页帖子已经绑定的第一张帖子附件批量取得，无图返回 `null`，临时/归档/回复/其他帖子附件不会泄露。

详情桌面使用约 144px 作者栏和专栏正文，正文实际阅读宽度约 680–760px。回复使用共享表面与楼层分隔线；手机将作者栏折叠成横向身份头。主帖和回复均为独立 `article`，正文与编辑预览共用唯一的 `F.markdown()` 白名单渲染器。

回复楼层按历史 `created_at + id` 稳定计算。`list_replies` 支持 `anchor_id` 定位目标页；通知与新回复跳转使用 `reply_anchor + #reply-{id}`。父回复必须同帖、已发布且未删除，API 仅返回安全纯文本摘要，编辑器只保存 `parent_reply_id`，不复制父正文或他人附件。

## 5. Markdown 创作工作台

发帖页最大宽度约 1200px，结构为标题、分类/标签、中央写作画布、正文图片媒体区和卡片内吸附操作栏。不显示无实际选择意义的发布范围。

编辑器默认使用受控 `contenteditable` 写作画布，Markdown 仍是唯一正文源：可视化 DOM 只用于输入，确定性的序列化器把它转换为 `body_md`；熟悉 Markdown 的用户可以切换到源码模式。浏览器不支持 `contenteditable` 时回退到源码模式，不阻止发布。

所有宽度使用“写作 / 预览 / Markdown 源码”可访问 Tab，默认打开写作：

- 工作区高度为桌面 `clamp(540px, 68svh, 760px)`，平板/手机为 `clamp(420px, 58svh, 620px)`。
- 写作画布和预览内容最大宽度约 760–820px，正文区域内部滚动，长图不会把整页无限拉长。
- 工具栏固定在写作面板顶部，字数/草稿状态位于面板底部；底部发布栏吸附在创作卡片内。
- 预览始终调用唯一的 `F.markdown()`，输入后 120ms 合并刷新，短状态显示“正在更新/已同步”；重渲染保存并恢复合法滚动位置。
- 非当前面板设置 `hidden` 与 `aria-hidden`，支持鼠标、触摸、方向键、Home 和 End；390px 下工具栏横向滚动，页面无横向溢出。

工具栏按标题、强调、列表/引用、代码、链接/图片分组，按钮至少 44×44px。“图片”直接调用现有上传器，不插入 `uploads/图片路径` 占位符。选择、拖拽或粘贴图片后立即显示本机 blob 缩略图；上传成功切到受信任服务器 URL、在当前光标插入 Markdown 并刷新预览；失败保留缩略图、原因、重试和删除。

富文本粘贴会将允许的段落、H2/H3、强调、列表、引用、代码、HTTP(S) 链接和 Forum 图片清理后转为 Markdown；脚本、样式、原始 HTML、外部图片、`data:`、`javascript:`、iframe 和表格不进入正文。输入 `## `、`### `、列表前缀或代码围栏后会自动建立块，Enter 会延续或退出列表/引用，完整 HTTP(S) 地址会在安全边界内自动转链。转换避开中文输入法组合状态并保留浏览器撤销。

媒体区显示“正文图片 N / 20”，桌面两列、手机单列。上传中禁用发布并显示“等待图片上传”。删除队列项会清理正文中该附件的全部规范化图片引用并释放 blob。

新草稿只保存标题、正文、分类、标签和时间；恢复旧草稿时忽略 `scope/club/country`。输入后延迟写入 `localStorage`，成功显示保存时间，失败显示错误但不清空正文。发布成功清除草稿和计时器，网络失败保留全部创作状态。

底部操作栏位于 `.create-card` 内并使用 `position:sticky`。桌面左侧显示状态、右侧显示取消与发布；手机状态独占第一行、两个按钮等宽，并处理安全区。离开卡片后自然停止，不覆盖页脚。

快捷回复保持单面板 Tab，只显示粗体、斜体、引用、行内代码、链接和图片；回复也复用受控 `contenteditable`、安全粘贴转换、智能输入和真实上传器，图片按钮直接打开上传并在当前光标处插入。显示回复字数和预览同步状态，提交失败保留正文、目标、上传队列和当前 Tab。

## 6. 主题、背景与页脚

三页共用主站 `theme-tokens.css`、`theme-runtime.js`、`page-background.js` 与 `VNFTheme`，并应用用户中心保存的全站壁纸偏好。Forum 不提供局部壁纸选择器，也不创建独立状态或存储键；页面只用 `--forum-*` 语义变量桥接深浅主题和壁纸表面，720px 以下或粗指针设备继续由公共模块关闭全屏壁纸。

三页均使用页面级页脚。广场额外显示真实帖子总数；社区规则、关于论坛、隐私政策使用 `#rules/#about/#privacy` 深链接对话框，支持直接访问、关闭、前进和后退。

## 7. 验收与发布边界

专项命令：

```powershell
node Forum/scripts/test-forum-contract.mjs
node Forum/scripts/test-forum-browser.mjs
php Forum/scripts/test-forum-v1.php
node scripts/test-display-club-contract.mjs
node scripts/test-user-page-assets.mjs
php -l Forum/api/forum.php
php -l Forum/includes/forum.php
php -l Forum/includes/forum_schema.php
```

合同测试固定 Forum 路径、广场-only API、无会籍/空间入口、真实上传按钮、编辑器挂载点、安全 Markdown、头像白名单、主题和响应式契约。SQLite 隔离测试验证首次/重复迁移、休眠分类/帖子/回复/附件/收藏仍存在但所有角色不可访问，以及广场标签、摘要、首图、附件归档、回复锚点和分类协调。

浏览器测试使用隔离模拟数据验证旧空间 URL 清理、不请求同好会目录、1440/1024 的居中写作画布与有界独立滚动、写作/预览/源码 Tab、图片按钮与即时缩略图、富文本粘贴转换、吸附栏、真实头像、主题流、详情楼层、页脚和深链接。

本轮不修改 Forum 自有表，也不删除或迁移休眠数据；账号共享结构新增 `users.display_membership_id` 与查询索引，旧账号默认 `NULL`，不自动回填。不引入第三方编辑器，不开放原始 HTML/外部图片/视频/iframe/表格，不执行生产迁移或正式部署。生产发布前仍需备份数据库和上传目录、先运行隔离迁移并验证 MySQL、再发布用户中心哈希资源与后端代码、刷新资源缓存，最后检查真实会话/通知/上传和历史休眠内容统一 404。
