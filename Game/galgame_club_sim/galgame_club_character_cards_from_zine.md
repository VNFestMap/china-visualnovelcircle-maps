# 《Galgame同好会模拟器》角色卡素材草案
> 用途：把《高校视觉小说同好会合同志：各同好会的发展历史》中出现的真实网名、社团形象、企划负责人和活动角色，抽象为游戏中的“核心成员角色卡”。
> 注意：这些卡片是**游戏化二次抽象**，不是现实人物完整画像。若后续公开发布或商业化，建议对名称、经历与台词进行进一步虚构化处理，避免直接对应现实个人。

## 设计字段说明
- **稀有度**：SSR / SR / R，仅代表游戏性能和剧情权重，不代表现实评价。
- **属性**：热情、组织、执行、内容、外联、传承、抗压，范围 0–100。
- **技能效果写法**：采用伪代码形式，方便 agent 后续转成 JS/JSON 数据。
- **缺点**：用于平衡数值，避免强卡无脑使用。
- **事件钩子**：适合后续扩展成个人事件、突发事件或剧情分支。

## 快速分类
- 当前共整理角色卡：**55 张**。
- 覆盖类型：创社、招新、社刊、外联、展会、原创 VN、平台、传承、社团形象、投票企划等。
